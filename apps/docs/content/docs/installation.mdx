Download the archive for your operating system and architecture from [GitHub Releases](https://github.com/neko233-com/acdesktop/releases). Extract the executable and its platform helper into the same directory on your PATH. The C library is distributed in a separate archive.

The install scripts support macOS ARM64 and Windows ARM64:

```bash
curl -fsSL https://raw.githubusercontent.com/neko233-com/acdesktop/main/scripts/install.sh | bash
```

```powershell
irm https://raw.githubusercontent.com/neko233-com/acdesktop/main/scripts/install.ps1 | iex
```

The scripts check the downloaded archive against the release checksum. Verify provenance separately:

```bash
gh attestation verify <downloaded-archive> --repo neko233-com/acdesktop
```

## Build from source

Install the Rust toolchain pinned by `rust-toolchain.toml` and your platform's C toolchain, then run:

```bash
git clone https://github.com/neko233-com/acdesktop
cd acdesktop
cargo build --release -p acdesktop
```

Build the platform helper beside the CLI on macOS or Linux:

```bash
cargo build --release -p acdesktop-macos --bin acdesktop-macos-helper    # macOS
cargo build --release -p acdesktop-linux --bins                          # Linux
```

## Verify the install

```bash
acdesktop version
acdesktop status
acdesktop skills get platform
```

`status` reports permissions and available surfaces. Grant Accessibility permission on macOS; on Linux, run inside the user's graphical session with an AT-SPI bus. Windows operations depend on the integrity level of the target process. See the platform guide for the full requirements.
