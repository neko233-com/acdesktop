## 2.0.0

- Distribute the CLI and C library as native archives.
- Schedule parallel batch operations by verified process identity and preserve the order of global input.
- Harden version checks, installation failures, and release asset verification.

## 1.2.0

- Rename the project to acdesktop.
- Add parallel batch execution, user configuration, native updates, and multi-display support.
